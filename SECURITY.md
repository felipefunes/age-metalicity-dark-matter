# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it privately rather than opening a public issue.

- Open a [GitHub Security Advisory](https://github.com/felipefunes/age-metalicity-dark-matter/security/advisories/new) for this repository, or
- Email felipefunes@gmail.com with details.

Please include steps to reproduce, the potential impact, and any suggested remediation. We aim to acknowledge reports within a few business days.
